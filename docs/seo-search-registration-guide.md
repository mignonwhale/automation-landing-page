# 구글/네이버 검색 노출 등록 가이드

랜딩페이지가 구글·네이버 검색 결과에 뜨려면 `robots.txt`/`sitemap.xml`만으로는 부족하고, 각 검색엔진에 직접 사이트를 등록해야 한다.

## 현재 준비된 것 (코드에 이미 반영됨)

- `app/robots.ts` — 모든 크롤러 허용
- `app/sitemap.ts` — 페이지 목록 제공 (`SITE_URL` 기준)
- `app/layout.tsx`의 `metadata` — OG/Twitter 카드 등 검색·공유 시 노출되는 제목/설명

이건 "크롤러가 방문했을 때 잘 읽을 수 있게" 준비해둔 것이지, 검색엔진이 실제로 사이트를 찾아와서 색인(인덱싱)하는 것과는 별개다.

## 왜 아직 검색에 안 뜨는가

- 새 사이트라 이 주소를 링크해주는 다른 사이트가 없어(백링크 0), 검색엔진이 자연스럽게 발견할 확률이 낮다.
- 구글/네이버 어디에도 아직 사이트를 직접 등록한 적이 없다.

## 구글 — Google Search Console

1. https://search.google.com/search-console 접속 (구글 계정 로그인)
2. **속성 추가** → URL 접두어 방식으로 배포 URL 입력 (예: `https://automation-landing-page-kappa.vercel.app`)
3. **소유권 확인** — 여러 방법 중 하나 선택:
   - HTML 태그 방식: 인증 코드를 `app/layout.tsx`의 `metadata.verification.google`에 추가하면 됨 (예: `verification: { google: '인증코드' }`) — 인증 코드만 알려주면 코드에 반영 가능
   - 또는 DNS 레코드 인증 (도메인 관리 콘솔에서 처리, Vercel 기본 도메인이면 HTML 태그 방식이 더 간단)
4. 인증 완료 후 **Sitemaps** 메뉴에서 `sitemap.xml` 제출 (`https://.../sitemap.xml`)
5. **URL 검사** 도구로 메인 페이지 URL 입력 → **색인 생성 요청** 클릭 (2026/07/23 완료)
6. 보통 며칠~몇 주 내 검색 결과 반영

## 네이버 — 네이버 서치어드바이저

1. https://searchadvisor.naver.com 접속 (네이버 계정 로그인)
2. **웹마스터 도구** → 사이트 등록 → 배포 URL 입력
3. **소유 확인** — HTML 태그 또는 파일 업로드 방식 중 선택 (HTML 태그 방식이면 구글과 마찬가지로 `layout.tsx` 메타데이터에 코드 추가)
4. 확인 완료 후 **요청 → 사이트맵 제출**에서 `sitemap.xml` URL 제출
5. **요청 → 웹페이지 수집**에서 메인 페이지 수집 요청

네이버는 구글보다 수동 등록 의존도가 높아서, 등록하지 않으면 사실상 검색에 거의 노출되지 않는다.

## 참고

- 소유권 인증은 각자의 구글/네이버 계정으로 직접 진행해야 하는 단계라 대신 처리할 수 없다. 인증 코드(메타 태그 값)만 전달하면 코드에는 바로 반영 가능하다.
- 배포 도메인이 `*.vercel.app` 형태라 전문성이 다소 떨어져 보일 수 있는데, 색인 자체에는 문제없다. 다만 커스텀 도메인으로 바꾸면 검색 결과에 더 신뢰감을 줄 수 있다 (`dev-plan.md`의 "향후 확장 여지" 참고).
