## 3. 해결책 섹션

**소제목**
자동화가 이렇게 해결합니다 — 지금 바로 실행해보세요

각 카드는 스크린샷 혹은 GIF + 설명 + 다운로드 버튼으로 구성. 이메일 입력 없이 즉시 다운로드.

1. **반복 작업 자동화 매크로**
   - 설명: 매일 반복하는 작업을 버튼 한 번으로 끝낼 수 있습니다.
   - 버튼: 매크로 샘플 다운로드

2. **엑셀 ↔ PDF 자동 변환**
   - 설명: 여러 문서를 자동으로 변환하여 반복적인 문서 작업을 줄여드립니다.
   - 버튼: 변환 샘플 다운로드

3. **VBA 맞춤 자동화 (축소 공개 버전)**
   - 설명: 회사 업무에 맞춘 자동화 프로그램으로 업무 효율을 높여드립니다.
   - 버튼: VBA 샘플 다운로드

**하단 보조 문구**
자동화 프로그램은 담당자가 바뀌어도 동일하게 작동합니다

**제작 시 참고사항**
- 모든 실행파일(exe)에는 스플래시 화면 또는 프로그램 정보(About)에 제작자명·연락처·사이트 링크 삽입
- VBA 샘플은 핵심 로직 전체가 아닌 기본 동작 원리 수준으로 축소 공개
- exe 파일은 zip 압축 배포 + "Windows 보안 경고는 정상입니다" 안내 문구 동반

## 6. 가격/FAQ + 최종 CTA 섹션

### 작업 규모별 시작가

| 구간 | 시작가 | 예시 |
|---|---|---|
| 아주 간단한 작업 | 3만원부터 | 매크로 버튼 하나 추가, 단순 서식 자동 채우기 |
| 일반 자동화 | 20만원대부터 | 데이터 정리·입력 자동화, 반복 보고서 생성 |
| 맞춤 자동화 | 문의 후 견적 | 여러 시트·파일 연동, 예외처리가 많은 작업 |

### 자주 묻는 질문

**Q. 견적은 어떻게 정해지나요?**
A. 작업 범위, 데이터 양, 예외처리 방식에 따라 달라집니다. 이메일로 문의 주시면 대략적인 범위를 먼저 안내해드려요.

**Q. 작업 기간은 얼마나 걸리나요?**
A. 간단한 작업은 1~2일, 맞춤 자동화는 3~5일 정도 소요됩니다.

**Q. 수정은 몇 번까지 가능한가요?**
A. 3만원대 작업은 1회, 20만원대 이상은 3회까지 무료 수정이 가능합니다. 이 외 추가 요청은 별도 협의합니다.

**Q. 소스 코드도 받을 수 있나요?**
A. 별도 프로그램(exe) 형태의 결과물은 소스코드를 제공하지 않습니다. 엑셀 매크로 형태의 결과물은 완성된 파일 그대로 전달해드리며, 별도의 코드 설명서나 문서화는 제공하지 않습니다.
